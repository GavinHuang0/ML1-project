# Results summaries

This directory is tracked in Git. The offline registration command creates `runs.json` here from completed original logs; it contains model tags, realized settings, counts, source and question-set checksums, source paths, and combined panel accuracy for all six methods. No index has been populated in this checkout yet.

Add reviewed tables, plots, and analysis notes here. Reference run paths and checksums, state question and repeated-run counts, and distinguish raw run summaries from statistically supported conclusions. Full response logs belong in the sibling `raw/` directory and remain ignored.

See the [stage record](../README.md) for registration instructions and [interpretation](../../interpretation.md) for conclusions.
