The earlier [October 24 archive](../2026-10-24-legacy/README.md) remains separate and unchanged. This snapshot does not recursively copy that archive. Model weights, environments, Git internals, generated bytecode, and operating-system metadata were excluded.

## Preserve historical meaning

Do not edit frozen files to reflect the active baseline. The entire snapshot is covered by byte-preserving Git attributes. Its reports describe results as understood at their original dates, and their former claims of active/fresh status do not apply to today's workflow.

Raw artifacts retain their original absolute paths, source strings, recorded commands, protocol identifiers, prompts, errors, and scores. Those strings are historical evidence and have not been rewritten. For a former repository-relative path such as `results/runs/...`, resolve it relative to this archive directory. The inventory maps every original path to its snapshot path; original absolute paths no longer identify the archived location.

Historical links beginning with `archive/2026-10-24-legacy/` refer to the existing sibling archive linked above, not a nested copy inside this snapshot. Use this index when a frozen document's original relative or absolute link no longer resolves from its new location.

The archived numerical-final-answer, calculator-expression, and exact-choice protocols have different scoring/delivery rules. Their original scores remain unchanged. No failed output was repaired during consolidation. The active historical-reference file selects the original calculator-prompt condition without relabeling any generation as a new run.

## Inspect archived code

The source snapshot is self-contained for historical inspection. To run its offline tests using the frozen imports rather than active modules, enter this directory explicitly:

```sh
cd archive/2026-11-09-pilots
python3 -B -m unittest discover -s tests -v
```

These tests use fixtures and a temporary local HTTP server, not installed-model inference. `-B` avoids writing bytecode into the snapshot. Do not run archived inference commands with their old default destinations; any deliberate reproduction should use a new output directory outside the archive and retain the historical protocol label. Archived old analyzers may contain generation-time absolute path strings; resolve data through this index rather than changing the preserved files.

Use the [current README](../../README.md) and `run_baseline.py` at the repository root for new experiments. The original `planner-calculator-v1` prompt, calculator, and scorer remain the active core, under the new organizational wrapper `calculator-baseline-v1`.
