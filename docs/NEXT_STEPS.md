# Next experiment steps

The active setup is fixed to `llama3.2:3b`, 1024 output tokens, and `posterior-v2` sensor correctness at absolute tolerance 0.001. The October 24 migration changes configuration, sensor scoring, and sensor panel aggregation; it does not run a new inference experiment. Historical results and their interpretations are in [the legacy archive](../archive/2026-10-24-legacy/README.md).

The [November 6 run](RESULTS.md) completed all 80 calls and established the current baseline. Every full-pilot method scored 0/4; all 58 valid full-pilot answers were wrong and two responses still truncated at 1024 tokens. The original urn math-check condition scored 2/2, while the diagnostic scored 2/8 to 3/8 with eight answer-contract failures, at least five containing correct mathematics in the explanation. All 20 single-agent texts reproduced the earlier Llama run exactly. Historical scores remain unchanged.

The [explicit template and bounded-explanation experiment](TEMPLATE_EXPERIMENT.md) is now implemented and completed: 12 fresh questions and eight regression items, each under two prompts, for 40 calls. On fresh questions, valid answers increased from 3/12 to 11/12 and strict correctness from 1/12 to 5/12. The regression comparison improved from 2/8 to 5/8 correct, with one mathematical regression. Most fresh gains recover missing final answers, and only 12/20 template responses obey the word limit. This is evidence for better delivery on the tested cases, not uniform improvement in mathematics.

The template's 5/12 correct fresh answers and 11/12 valid outputs are adequate to proceed to a small controlled development pilot: there are now both correct answers that could be corrupted and errors that could be repaired. Twelve questions do not establish a dependable baseline accuracy, and the template has not yet established a sensor-posterior baseline. Freeze the candidate instead of continuing to tune it on these inspected questions.

The next pilot should use a fresh, larger question set and compare self revision with peer discussion using the same initial answers. Keep Llama, 1024 tokens, matched seeds, and no calculator or answer retries. Include sensor questions and report each family separately; assess them with the exact posterior tolerance. Report required-field validity, final-answer correctness, consistency with explanations, and budgets separately. Never extract a number from prose to rescue historical scores. This comparison remains a proposed next experiment; the existing three-profile suite's prompts remain unchanged.

For sensors, headline correctness must use the exact posterior tolerance rather than agreement with a hidden-state decision. Before a larger evaluation, build a balanced development set with varied posterior strengths and both hidden states, then freeze prompts and evaluate on separate held-out questions. Related variants must stay in the same split. Any later communication comparison needs an independent-answer baseline with comparable call budgets and separate input/output token accounting.
